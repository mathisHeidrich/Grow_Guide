# Check-In Timing Logic
*Neu/Erweitert (Aus Checkin Logic Plan)*
- *Goal:* Das Problem mit der starren 24-Stunden-Regel beheben, damit Nutzer nicht einen Tag aussetzen, wenn sie abends gemessen haben.
- *Solution:* Wir implementieren einen Kalendertage-Reset (Option A) oder Morgen-Reset (Option B) anstelle von exakt 24h.
