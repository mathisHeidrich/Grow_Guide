# Grow Guide V2: Onboarding & Keimungs-Tutorial (Wasserglas-Methode)
Version: 1.1.0

## Grundlogik des Setup-Wizards
Wenn ein Nutzer eine neue Pflanze im Dashboard anlegt, befindet sich diese im Status `Samen`. Anstelle des regulären Check-In Buttons zeigt die Pflanzenkarte den Button **`🚀 Start`**.
Klickt der Nutzer darauf, öffnet sich ein Step-by-Step Wizard im selben UI-Design wie der Check-In, um den Nutzer fehlerfrei durch die ersten Tage zu leiten.
