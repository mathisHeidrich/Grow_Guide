# Plan: Check-In Timing Logic (Kalendertage)

## Goal
Das Problem mit der starren 24-Stunden-Regel beheben, damit Nutzer nicht einen Tag versehentlich aussetzen, weil sie am Vortag abends gemessen haben.

## Lösungs-Optionen:
- Option A: Kalendertage (Reset um 0:00 Uhr).
- Option B: Morgen-Reset (Reset um 06:00 Uhr morgens).
- Option C: Hybrid (Neuer Tag + 12 Stunden Sperre).

Warte auf User Feedback.
